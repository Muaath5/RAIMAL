What this MVP demonstrates

The bundled dataset is synthetic. The desk replays actual Python Isolation Forest outputs and supports imports of analysis bundles produced from satellite-derived observation CSVs. The browser displays saved model outputs; it does not download rasters or train a model. Imported source identifiers and geometry are user supplied. Field accuracy, water savings and customer results have not been measured. Historical candidates require human review.

Use the included Python exporter to prepare an import. Download the CSV schema · Read setup instructions
